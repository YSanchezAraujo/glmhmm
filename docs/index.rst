
Welcome to GLM-HMM's documentation!
===================================

**glmhmm** is a JAX-based package for Generalized Linear Model Hidden Markov Models (GLM-HMM).
It supports various emission types including **Bernoulli**, **Multinomial**, **Gaussian**, **Negative Binomial**, and **Gamma**.
Features include **Input-Driven Transitions** and rigorous **Model Selection** via Bayesian Quadrature and Sequential Monte Carlo.
